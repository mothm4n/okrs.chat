## What to build

Dar a quienes escriben y mantienen el Journal una referencia verificable para usar todos los elementos de contenido soportados y evitar que cambios futuros degraden la experiencia de lectura.

## Acceptance criteria

- [x] Existe una muestra de contenido que representa los elementos de artículo soportados y permite detectar regresiones de estilo.
- [x] La verificación del sitio comprueba que la muestra y las entradas publicadas se generan sin errores ni pérdida de estructura semántica.
- [x] La guía de autoría aclara cuándo usar encabezados, citas, listas, tablas, código, imágenes y desplegables, incluido el límite de una `h1` por entrada.
- [x] La comprobación visual confirma contraste, foco visible, movimiento reducido y ausencia de desbordamiento en los cuatro anchos de referencia.
